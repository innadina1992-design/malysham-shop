# Малышам — прототип MAX Mini App

Откройте `index.html` в браузере для тестирования каталога, корзины и формы.

Это **демонстрация**, не действующий интернет-магазин: форма не отправляет заказ, платежи не проводятся, доставка не рассчитывается, персональные данные не сохраняются на сервере.

## До запуска
1. Разместить фронтенд на HTTPS-домене.
2. Создать backend/API и базу данных товаров и заказов, серверный пересчёт цен и остатков.
3. Валидировать `window.WebApp.initData` по официальному алгоритму MAX, проверять `auth_date` и привязывать заказ к подтверждённому пользователю.
4. Реализовать идемпотентное создание заказов, подтверждение, статусы и уведомления через MAX Bot API. Токен бота хранить только на сервере.
5. Подключить API СДЭК и Почты России, адреса/ПВЗ, расчёт тарифов и отслеживание.
6. Подключить эквайринг, онлайн-кассу/чеки, проверку webhook платежей на сервере.
7. Добавить действующие политику обработки персональных данных, согласие, оферту, реквизиты ИП, условия доставки и возврата.
8. Добавить фотографии реальных товаров и панель управления каталогом.
9. В настройках бота MAX вставить HTTPS URL приложения, выбрать кнопку «Открыть» и сохранить.

Официальные документы: https://dev.max.ru/docs/webapps/introduction и https://dev.max.ru/docs/webapps/validation
